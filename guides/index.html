Setup guides

Set up your IPTV player with confidence.

These guides explain the supported LibertyVue Player connections and the steps needed to add your own or properly licensed media.

ANDROID / FIRE
▣

Install on TV & Fire Stick

Install the APK directly or via Downloader, open the app and connect an authorised playlist.

  1. Download from the download page
  2. Allow unknown sources, install
  3. Add M3U or Xtream, refresh
PLAYLIST FORMATS
≣

M3U or Xtream Codes

Choose the right connection method and keep your playlist credentials private.

  • M3U — one link, simplest
  • Xtream — server + login, faster + EPG
WHILE WATCHING
◎

Remote shortcuts

CH +/− or arrows zap without leaving playback. OK opens categories and the channel list. Back returns to the library.

✓

Use content you are allowed to watch.

LibertyVue Player is software only. It does not include channels, subscriptions or playlists. Add personal media or a playlist from a provider authorised to distribute it.
